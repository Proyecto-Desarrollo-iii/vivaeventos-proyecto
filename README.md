# VivaEventos - Proyecto Multi-Repo

Repositorio principal que consolida todos los microservicios del sistema.

## Estructura

```
vivaeventos-proyecto/
├── vivaeventos-gateway/        # API Gateway (8080)
├── vivaeventos-events/         # Gestión de eventos (8081)
├── vivaeventos-tickets/        # Boletas y QR (8082)
├── vivaeventos-orders/        # Órdenes (8083)
├── vivaeventos-payments/       # Pagos (8084)
├── vivaeventos-checkin/       # Check-in (8085)
├── vivaeventos-notifications/   # Notificaciones (8086)
├── vivaeventos-analytics/       # Analytics (8087)
├── vivaeventos-auth/           # Autenticación (8088)
├── vivaeventos-audit/        # Auditoría (8089)
└── vivaeventos-infra/       # Infraestructura
```
